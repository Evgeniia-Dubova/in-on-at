# IN · ON · AT — тренажер прийменників

Наочний сайт-тренажер для правил вживання **in / on / at**: таблиця правил із перекладом, ілюстровані приклади, де самі прийменники стали героями, режим «Перевір себе» і міні-гра «Розсели героїв».

**Сайт:** https://evgeniia-dubova.github.io/in-on-at/

## Файли
- `index.html` — сторінка
- `style.css` — скляний стиль і градієнт
- `app.js` — таблиця правил, приклади, режим «Перевір себе»
- `scenes.js` — ілюстрації-сценки (SVG)
- `game.js` — міні-гра «Розсели героїв»
- `place.js` — гра «Постав героя»
- `icons.js` — лінійні іконки [Lucide](https://lucide.dev) (ISC License)

Статичний сайт без збирання: GitHub Pages віддає файли напряму.
